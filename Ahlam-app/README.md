# Ahlam Live Voice Chat App 🎙️✨

تطبيق **Ahlam (أحلام)** هو منصة لايف ومحادثات صوتية جماعية مشابهة لمزايا تطبيق *Yaahlan*، يدعم إنشاء غرف حفلات، توزيع مقاعد الميكروفون، شات مباشر ونظام تحديات الدعم الفوري (PK Live).

## ✨ المزايا الحالية
- نظام دخول ذكي بواسطة المعرف (User ID).
- لوحة غرف متعددة لإدارة الحفلات الصوتية.
- 6 مقاعد صوتية لايف متزامنة لكل غرفة.
- نظام تحدي الـ PK ومحاكاة إرسال الهدايا الافتراضية مع شريط مؤشرات فوري.

## 🚀 طريقة التشغيل محلياً
1. قم بتحميل الملفات وتثبيت حزم البرمجة:
   ```bash
   npm install
   ```
2. قم بتشغيل السيرفر الرئيسي:
   ```bash
   npm start
   ```
3. افتح الرابط في المتصفح الخاص بك: `http://localhost:3000`
